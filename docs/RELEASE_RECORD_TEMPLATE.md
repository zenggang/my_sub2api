# 发布记录：填写版本与日期

状态：准备中 / 构建通过 / 候选通过 / 已部署待业务验收 / 验收完成 / 已回滚 / 阻塞。

## 范围与来源

- 用户授权范围、目标组件及环境：
- 代码分支、官方基线 SHA、自有 commit、源码 tree：
- 实际构建来源模式（官方 tag＋补丁 / 已验证的 fork 构建器）：
- 发布前运行版本、二进制 SHA、PID、核验时间：
- 目标版本、源码/补丁差异、数据库迁移差异及处理结论：
- 发布工具版本/文件 SHA；与服务器入口是否一致：

## 编译与打包

- Go / Node / pnpm / Python 的可执行路径与实际版本：
- PREPARED 目录、实际编译命令或对应日志：
- 前端锁定安装、i18n、类型检查、构建结果：
- Go 必要测试名称、实际通过事件、失败/跳过项：
- 目标架构、CGO/嵌入参数、版本/commit/Date 字段：
- binary SHA、源码归档 SHA、分发包 SHA、manifest 和 SHA256SUMS：
- 包内容及解包校验结果：

## 候选与部署

- STAGED 目录、服务器预检结果：
- 候选监听、所用测试 Key ID（不写明文 Key）：
- 测试矩阵、每轮 request ID、真实终态、下游/上游模型及账号：
- SMOKE_VERIFIED.sha256 是否匹配本次候选；候选是否已停止：
- 活动请求与账号并发核验时间及结果；若强切换，记录用户明确授权：
- 实际部署命令、起止时间、备份目录及兼容性：
- 部署后版本、二进制 SHA、PID、健康与配置/映射一致性：

## 业务验收与回滚

- 正式入口请求 ID、工具调用/续聊或相关业务终态：
- 日志与 usage 回查时间窗、按 request 去重后的结果：
- 新增错误分类；已恢复重试与最终失败分别记录：
- 如回滚：触发原因、实际步骤、恢复 SHA、健康和真实请求结果：
- 数据库是否变化及恢复方式（不能仅写“二进制已回滚”）：
- Git 合入/推送状态、最终 release SHA；官方 PR/部署状态分别说明：
- 未验证项、遗留问题、下次必须处理的工具变化：
